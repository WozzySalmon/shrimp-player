# 🦐 Shrimp Player

A local music player written in Rust, for Windows, Linux and Android. Its shrimp mascot dances to whatever you're playing.

It's early days: the design is settled and the code hasn't started yet. See [`docs/SPEC.md`](docs/SPEC.md).
