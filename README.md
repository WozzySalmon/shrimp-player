# 🦐 Shrimp Player

A local music player written in Rust, for Windows, Linux and Android. Its shrimp mascot dances to whatever you're playing.

It's early days. The design is in [`docs/SPEC.md`](docs/SPEC.md), and the headless core (`crates/shrimp-core`) is being built now.

## Building

```sh
cargo build --workspace
cargo test --workspace
```
